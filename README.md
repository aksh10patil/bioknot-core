# BioKnot-Core Platform

Hybrid Topological Protein Knot Detection & WASM 3D Structure Bridge.

- **Native Transformer AI**: Instant topological classification ($0_1$, $3_1$, $4_1$, Complex).
- **Sub-Domain Window Scanner**: 400 AA sliding window evaluation for long polyproteins.
- **WASM / WebGL 3D Bridge**: Interactive C-alpha backbone visualization powered by Molstar.
